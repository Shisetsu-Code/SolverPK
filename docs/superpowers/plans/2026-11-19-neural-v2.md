# Neural v2 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Coordinate shared interfaces before edits.

**Goal:** Corregir información y aprendizaje neuronal, conservar evaluación legacy y medir la versión nueva con rivales diversos.

**Architecture:** Encoder versionado 128D; MLP existente de 32 unidades ocultas; gradiente agregado por mano sobre parámetros congelados. Checkpoint v2 con segmentos reproducibles y liga independiente del entrenamiento.

**Tech Stack:** Rust stdlib; GitHub Actions para compilación/pruebas; Python stdlib solo para orquestación de evidencia.

**Spec:** `docs/superpowers/specs/2026-11-19-neural-v2-design.md`.

## Global Constraints

- No dependencias Rust nuevas; conservar contabilidad `accounting-v2`.
- Legacy SPKNN001 es evaluable, no entrenable; no sobrescribir el checkpoint 100M.
- INPUT=128; LEGACY_INPUT=64; HIDDEN=32; ACTIONS=6.
- Retorno = neto/(BB_UNITS*100); sin clipping de retornos, ventajas o norma.
- Las pruebas Rust se ejecutan en CI; no instalar toolchains locales.

## Review Focus

1. Asociación rango/palo y ausencia de cartas futuras/ajenas: fixtures de encoder.
2. Valor monetario no lineal o ponderación por decisiones: diferencias finitas y lote con longitudes distintas.
3. Política/baseline que cambia durante una mano: gradiente congelado y reversión de orden.
4. Pérdida de procedencia o cambio silencioso de versión: legacy golden, resume idéntico, archivo truncado y modo no entrenable.
5. Falsa separación de test o modificación durante evaluación: colisiones XOR/RNG, rival entrenado y bytes congelados.
