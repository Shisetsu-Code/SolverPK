[Actions 44564068762](https://github.com/Shisetsu-Code/SolverPK/actions/runs/44564068762).

requiere su código y archivos originales; no equivale a entrenar con el motor
actual. Para nuevos experimentos se usa
[neural-v2-train.yml](../../../.github/workflows/neural-v2-train.yml).
